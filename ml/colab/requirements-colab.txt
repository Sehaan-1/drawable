# LineScout · Colab GPU environment (pinned)
#
# One place that says which *pip* packages the Milestone 2 pipeline runs on.
# `linescout_gpu_pipeline.ipynb` installs from this file, `linescout-repro
# environment` reads it locally, and CI (tests/test_colab_repro.py) checks that
# every pin below still equals the version in the committed `ml/uv.lock`, so the
# runtime a Colab user gets and the runtime CI type-checks are the same set of
# numbers.
#
# torch and torchvision are *deliberately* not installable from here. Colab ships
# a CUDA build matched to the host driver; letting pip resolve them again is the
# classic way to end up with a CPU-only torch or a broken cuDNN. The notebook
# freezes whatever it finds into a constraints file instead, and records the real
# versions in the run report. The `[runtime]` group below is documentation and
# drift-detection only — nothing in it is ever installed.
#
# Groups (a `# group:` header applies to every pin under it):
#
#   [base]        imported by every stage, CPU and GPU alike
#   [extraction]  controlnet_aux + its image stack (RUN_EXTRACTION)
#   [clip]        open_clip + timm for MobileCLIP2 labels/features (RUN_LABELS, RUN_EMBEDDINGS)
#   [nsfw]        opennsfw2 for sources whose terms do not guarantee SFW content
#   [display]     notebook progress bars and previews
#   [runtime]     reference versions; never installed
#
# A run installs only the groups its toggles and resolved sources need — see
# linescout_ml.colab.repro.plan_environment. Add a dependency by adding a line
# under the right group; the notebook needs no edit, because it installs by group.
